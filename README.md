\# Mini SOC — 공격·탐지 자동화 실습



격리된 로컬 실습 환경에서 공격 행위를 재현하고,

로그 수집부터 탐지 규칙 작성, 검증, 분석 보고서 작성까지 수행하는 개인 보안 프로젝트입니다.



\## 프로젝트 목표



\- 보안 로그의 수집·분석 흐름 이해

\- 공격 시나리오별 탐지 규칙 작성

\- MITRE ATT\&CK 기반 공격 행위 분류

\- 탐지 성공 여부와 오탐·미탐 분석

\- 실습 환경과 검증 절차 자동화



\## 구성 계획



| 구성 요소 | 도구 및 역할 |

|---|---|

| 작업 환경 | Windows CMD, Git |

| 실습 환경 | Docker Desktop, WSL2 |

| 로그 수집·분석 | Wazuh 도입 예정 — 자원 확인 후 확정 |

| 버전 관리 | GitHub |



\## 첫 번째 실습 시나리오



SSH 로그인 반복 실패 탐지



1\. 로컬 실습용 SSH 서버 구성

2\. 통제된 로그인 실패 이벤트 생성

3\. 인증 로그 수집

4\. 반복 실패 탐지 규칙 작성

5\. 정상 로그인과 비교하여 탐지 결과 검증

6\. 분석 결과와 개선 사항 문서화

공격 재현은 본인이 소유하고 통제하는 로컬 실습 환경에서만 수행합니다.

비밀번호, 토큰, 개인 키, 개인정보가 포함된 원본 로그는 저장소에 올리지 않습니다.
